# 📚 주목 논문

## 1. RepoFactory — 훈련 환경도 루프로 진화시킨다

- **저자**: Yang Tian, Tianyu Zheng 외 8인
- **arXiv**: [2611.21152](https://arxiv.org/abs/2611.21152) (cs.CL, v2 11/16)
- **핵심 기여**: 실제 레포지토리를 "언어 스펙만 보고 프로젝트를 밑바닥부터 짓는" 검증 가능 훈련 환경으로 자동 변환하는 파이프라인. 기존 환경 합성이 "검증 통과"에서 멈추는 것과 달리, **유효성 × 구조 결합도 × 구현 범위**라는 프록시 신호의 곱을 최적화하는 환경 진화 루프를 돌린다.
- **방법**: 모델 롤아웃·재학습 같은 비싼 피드백 대신 즉시 계산 가능한 프록시 신호로 환경을 고쳐 쓰고, 17개 도메인에서 환경 10,159개를 합성.
- **결과**: 이 환경으로 Qwen3.5-35B-A3B를 훈련한 RepoHorizen-35B-A3B가 NL2Repo-Bench **+22.6pp**, 5개 벤치 평균 +8.5pp. 진화 루프를 빼면 +17.5pp / +6.4pp로 떨어진다 — 루프 자체의 기여가 분리 검증됐다.
- 🛠 **시사점**: 에이전트 RL의 병목은 환경 공급이다. "환경의 훈련 가치"를 롤아웃 없이 추정하는 프록시 지표 설계는 사내 에이전트 평가셋을 키울 때도 그대로 써먹을 수 있는 아이디어.
- **한계**: 프록시 신호가 실제 다운스트림 성능과 어긋나는 영역이 있는지는 5개 벤치 밖에서 검증되지 않았다.

*RepoFactory의 방법 요약. 막대 수치는 논문 초록 기재값.*

## 2. 자기 개선, 아직도 "방법"을 알려줘야 하나?

- **저자**: Shobhita Sundaram, Cansu Sancaktar, Phillip Isola (MIT 중심)
- **arXiv**: [2611.23219](https://arxiv.org/abs/2611.23219) (cs.LG, 11/17)
- **핵심 기여**: 지금까지의 자기 개선 연구는 사람이 설계한 루프(리플렉션, 커리큘럼 등)에 모델을 끼워 넣었다. 이 논문은 반대로 **고정된(frozen) 에이전트에게 컴퓨트 예산, 경험 수집 도구, 텍스트 문서 업데이트 권한만 주고** 자기 학습 알고리즘을 스스로 구성하게 했다.
- **방법**: 게임플레이를 테스트베드로, 외부에서 루프를 강제하지 않고 자유 실험 허용. 학습 결과물은 가중치가 아니라 텍스트 아티팩트(컨텍스트 기반 최적화).
- **결과**: 충분히 유능한 모델은 이 조건에서 실제로 자기 개선에 성공했고, 자기조절학습(self-regulated learning)·자기 생성 커리큘럼과 맞닿는 전략이 자발적으로 나타났다. 배운 텍스트 아티팩트는 다른 게임 호라이즌·메커닉·3D 내비게이션 벤치로도 전이됐다.
- 🛠 **시사점**: 에이전트 하네스에 하드코딩하던 개선 루프 일부를 "루프 설계권 위임 + 결과물은 텍스트 아티팩트로 저장" 패턴으로 바꿀 수 있다는 초기 증거. 아래 공통 팁에서 구체화.
- **한계**: 게임 도메인 중심이라 실패 비용이 큰 실무 과제(코드 배포 등)에서의 안전한 위임 범위는 별개 문제다.

# 🧑‍💻 Codex & Claude Code 실전 팁

### 🟦 Claude Code — MCP 토큰, 셸 히스토리에 남기지 않기

- **카테고리**: MCP · **출처**: [CHANGELOG 2.1.327](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
- 💡 `claude mcp add-json <name> -`가 새로 생겼다. 서버 JSON을 **stdin으로** 받는다.
- 📝 지금까지는 토큰이 든 JSON을 커맨드라인 인자로 넘겨 셸 히스토리에 남았다. 이제:

```bash
cat server.json | claude mcp add-json my-server -
# 또는 시크릿 매니저에서 바로
op read "op://dev/mcp-config" | claude mcp add-json my-server -
```

- 🎯 API 키가 들어가는 원격 MCP 서버를 등록할 때. CI 스크립트에서 특히 유용.
- ⚠️ Claude Code 세션 내부에서는 쓸 수 없다(터미널 전용). 같은 버전의 `/status`에 깨진 스킬·에이전트·훅 목록이 추가됐으니 설정 점검도 겸사겸사.
- ⭐ 추천도: 토큰을 다루는 팀이라면 오늘 바로 습관 교체.

### 🟩 Codex — stdio MCP 서버, 이제 기본이 지연 기동

- **카테고리**: MCP · **출처**: [commit 637c429 (11/18)](https://github.com/openai/codex/commit/637c42947236017bc78da59d1a22916400ccae63)
- 💡 `mcp_lazy_stdio_startup`이 stable로 승격되고 **기본 활성화**됐다. 툴 카탈로그가 캐시된 optional stdio 서버는 첫 툴 호출 때까지 프로세스를 띄우지 않는다.
- 📝 MCP 서버를 여러 개 등록해둔 세션의 시작이 가벼워진다. required로 지정한 서버는 여전히 시작 시 연결. 예전 동작이 필요하면:

```toml
# ~/.codex/config.toml
[features]
mcp_lazy_stdio_startup = false
```

- 🎯 무거운 stdio 서버(브라우저, DB 클라이언트)를 "가끔 쓰는" 세션.
- ⚠️ 첫 호출에 기동 지연이 끼어든다. 서버가 시작 시점에 환경을 검증하는 타입이면 오류가 첫 호출 때로 미뤄진다는 점도 주의.
- ⭐ 추천도: 기본값이 바뀐 것이니 "내 서버가 안 떠 있다"고 당황하지 않도록 알아만 둬도 충분.

### 🟪 공통 — 자기 개선 루프를 위임할 때의 최소 골격

- **카테고리**: Workflow · **출처**: [arXiv 2611.23219](https://arxiv.org/abs/2611.23219)
- 💡 위 MIT 논문의 설정을 실무 에이전트에 옮기면: **(1) 명시적 컴퓨트 예산, (2) 경험 수집 도구, (3) 쓰기 가능한 텍스트 아티팩트(메모리/플레이북), (4) 외부 전이 평가** — 이 4개만 사람이 정하고 루프 설계는 모델에 맡긴다.
- 📝 예: 야간 배치로 "오늘 실패한 태스크 로그를 읽고, 플레이북.md를 수정하고, 고정 평가셋 10개로 전후 점수를 기록하라. 예산은 N 토큰"을 돌린다.
- 🎯 하네스에 리플렉션 로직을 하드코딩하다가 유지보수가 버거워졌을 때.
- ⚠️ 평가 게이트 없이 아티팩트 수정만 허용하면 그럴듯한 쓰레기가 쌓인다. 전이 평가(루프 밖 벤치)가 핵심 안전장치.
- ⭐ 추천도: 주말 실험으로 강력 추천.
