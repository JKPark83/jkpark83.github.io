# 🔥 오늘의 핵심

프론티어 모델 발표는 없었지만, "에이전트 여러 개를 겹치지 않게 굴리는 법"이라는 한 가지 주제가 논문·오픈소스·CLI 릴리즈에서 동시에 나온 하루다. NVIDIA 계열 저자들의 **Agora**는 Git 커밋 DAG를 에이전트 공유 메모리로 썼고, DeepSeek의 **deepseek-harness**와 **Orca**는 각각 하네스와 오케스트레이터 계층을 오픈소스로 채운다. 오늘 해볼 일: 병렬로 돌리는 에이전트들이 서로의 결과를 어디서 읽는지 — 그게 없다면 지금은 중복 탐색에 돈을 내는 중이다.

# 🤖 모델 & 릴리즈 레이더

오늘은 큰 모델 소식 없음. 대신 코딩 CLI 두 개가 같은 날 움직였다(둘 다 이 세션에서 태그 목록·클론으로 확인).

- **Codex CLI 0.155.0 (9/17)** — 실험 기능으로 **`/voice` 음성 대화**(라이브 트랜스크립트 + 마이크 컨트롤)가 들어왔고, TUI 상태줄에 라이브 추론 요약과 턴 완료 타임스탬프가 표시된다. 에이전트 오버뷰에서 태스크 숨김·보관·삭제와 관리형 워크트리 정리가 가능해졌고, Mac에서는 **MCP 요청에 Touch ID 검증**을 붙일 수 있다. 에이전트를 "여러 개 띄워놓고 관리하는" UI가 릴리즈마다 두꺼워지는 중. [릴리즈 노트](https://github.com/openai/codex/releases/tag/rust-v0.155.0)
- **Claude Code 2.1.274** — MCP 연결 문제를 한꺼번에 손봤다. 긴 `timeout` 설정에도 약 5분에 끊기던 Streamable HTTP 호출, 첫 요청에 4xx로 답하는 레거시 HTTP+SSE 서버 연결 실패, 403을 "로그인 만료"로 뭉개던 표기가 모두 수정. 손상된 트랜스크립트로 인한 `tool_use_id` 400 무한 재시도 루프도 자가 복구된다. MCP 서버를 여러 개 물려 쓰는 세팅이라면 체감이 클 릴리즈. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

# 📚 주목 논문

## Agora: Git을 멀티에이전트 공유 메모리로 (arXiv 2609.18094, cs.LG)

- **저자**: Yifan Zhang, Yunheng Zou, Shaokun Zhang, Jian Hu, Hao Zhang, Binfeng Xu, Jan Kautz, Yi Dong — NVIDIA(HF Daily 표기 기준, 9/16 공개, 오늘 HF Daily 39 upvotes)
- **핵심 기여**: 자율 연구 에이전트를 여러 개 돌리면 각 세션이 처음부터 다시 시작해 **중복 탐색만 늘어난다**는 문제를, "연구 기록 = Git에 저장된 append-only DAG"로 푼다. 결과·인사이트·가설·검증·리포트가 각각 불변 커밋이고, 부모 엣지가 "무엇 위에 쌓였는지"를 말한다.
- **방법**: 파생 인덱스가 탐색 프론티어·방치된 브랜치·주장별 검증 상태를 노출하고, 다양성 인지 선택 규칙이 1등 레시피로의 쏠림을 막는다. 모든 주장은 체크아웃해서 재실행할 수 있다.
- **검증된 결과(초록 기준)**: 13개 LM 워커가 태스크 할당도 중앙 플래너도 없이 12일간 가중치 전이 문제를 공략 — 1,703개 기여를 발행하고 평가 지표를 3.39 → 1.899 bits/byte로 내려 **학습된 GPT-2 124M과의 갭 62%를 해소**했다(학습 데이터·그래디언트 없이). 우승 레시피의 조상 커밋은 15개 계정에 걸친 145개, 독립 재현 165건 중 실패 0.
- 🛠 **에이전트 빌더 시사점**: 멀티에이전트 "공유 메모리"에 새 인프라가 필요 없다는 주장 — Git이면 불변성, 출처, 재현 가능성이 공짜로 온다. 아래 공통 팁에서 축소판 패턴으로 이어짐.
- **한계**: 저자들 스스로 "공유 연구 상태가 컴퓨트당 발견을 정말 늘리는지"는 통제 비교가 남았다고 명시. 사람 개입도 1회 있었다(모노컬처 탈출).
- [arXiv 링크](https://arxiv.org/abs/2609.18094)

![Agora 구조](/images/ai-news-2026-09-18/agora-dag.svg)

*워커 → 커밋 DAG → 파생 인덱스 → 선택 규칙으로 도는 Agora 루프와 12일 운영 결과.*

## ProgramDistill: 돌아가는 앱에서 SWE 태스크를 증류 (arXiv 2609.18805, cs.SE)

- **저자**: Jeonghye Kim, Minseon Kim, Young Jin Kim, Matheus Pereira, Marc-Alexandre Côté 외 3인 — Microsoft Research(HF Daily 표기 기준, 9/16 공개, 44 upvotes)
- **핵심 기여**: 이슈 텍스트가 아니라 **동작하는 레퍼런스 앱과의 상호작용**으로 요구사항을 파악해 미완성 앱에 구현하는 벤치마크. 실무 웹 개발의 "저 앱처럼 만들어줘" 시나리오를 처음으로 체계화했다.
- **방법**: 앱을 여러 granularity의 기능으로 분해하고, 각 기능에 gold patch로 재생 가능한 동작을 연결. mine-craft-patch 파이프라인이 사람 개입 없이 26개 앱에서 재생 검증된 동작 1,975개, 태스크 4,063개를 만든다.
- **검증된 결과(초록 기준)**: 프론티어 에이전트 9종 평가에서 전체 앱 재구성 누적 워크플로 성공률은 GPT-6 Astra 49.2%, Claude Opus 5 28.8%. 부분 재구성에선 복원 깊이가 1 → 8로 늘면 성공률이 100% → 64%, 96% → 32%로 급락.
- 🛠 **에이전트 빌더 시사점**: 자체 코딩 에이전트 평가 세트가 궁색하다면 이 방식이 답이 될 수 있다 — 이슈 데이터셋 대신 잘 돌아가는 사내 앱에서 태스크를 증류하면 난이도 조절(복원 깊이)까지 공짜.
- **한계**: 웹 앱 도메인 한정. "동작을 스스로 발견하는" 능력과 "패치 작성" 능력이 섞여 측정된다.
- [arXiv 링크](https://arxiv.org/abs/2609.18805)

# 🛠 오픈소스 스포트라이트

두 저장소 모두 이 세션에서 클론으로 검증했다(마지막 커밋 둘 다 9/17). star 수는 GitHub API 접근 제한으로 미확인 — 둘 다 이번 주 트렌딩 상위권으로 집계되고 있다.

- **[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)** (TypeScript, MIT) — DeepSeek 공식 에이전트 하네스 `dsh`. **everything-is-a-plugin** 아키텍처로, 모델·툴·UI까지 전부 플러그인으로 갈아끼운다(플러그인 런타임은 Cordis). `npx @deepseek-ai/dsh web` 한 줄로 로컬 Web UI(기본 127.0.0.1:3080)가 뜬다. 현재 developer preview(0.1.6-alpha.2)로 호환성 파괴 변경을 예고하고 있다. **활용처**: Claude Code/Codex 같은 완제품 대신 하네스 내부를 뜯어 조립하고 싶은 팀 — 자체 플러그인은 `dsh-plugin` 토픽으로 공유하는 생태계까지 설계돼 있다.
- **[stablyai/orca](https://github.com/stablyai/orca)** (TypeScript/Electron, MIT) — "100x 빌더를 위한 오케스트레이터"를 표방하는 ADE(Agent Development Environment). **Codex·Claude Code·OpenCode·Pi를 각자의 git worktree에서 나란히** 돌리고 한 화면에서 추적한다. 프롬프트 하나를 에이전트 5개에 부채꼴로 뿌려 결과를 비교·머지하는 워크플로, 재시작에도 살아남는 터미널 스플릿, 에이전트가 끝나면 폰으로 알림을 받는 모바일 컴패니언(iOS/Android)까지. **활용처**: 터미널 탭 지옥에서 에이전트 병렬 실행을 관리하는 팀 — 어제까지 다루던 "Codex 에이전트 오버뷰"의 서드파티·멀티 CLI 버전이다.

# 🧑‍💻 Codex & Claude Code 실전 팁

**🟩 Codex / Workflow — `/experimental`로 `/voice` 음성 세션 켜기**

- 출처: [rust-v0.155.0 릴리즈 노트](https://github.com/openai/codex/releases/tag/rust-v0.155.0)
- 💡 핵심: 0.155.0부터 지원 빌드에서 WebRTC 기반 음성 대화가 실험 기능으로 들어왔다. 말로 지시하고, 라이브 트랜스크립트로 확인한다.
- 📝 방법:

```text
codex 실행 → /experimental 에서 voice conversations 활성화
→ /voice 로 세션 시작 (마이크 컨트롤 + 라이브 트랜스크립트)
```

- 🎯 언제: 손이 키보드를 떠나 있는 리뷰·탐색 세션, 또는 긴 지시를 타이핑 없이 던질 때.
- ⚠️ 주의: 실험 기능이고 "지원 빌드" 한정 — 플랫폼별로 아직 고르지 않다. 트랜스크립트를 확인하고 실행 승인하는 습관은 유지할 것.
- ⭐ 추천도: 얼리어답터용. 음성 UX 자체보다 "코딩 CLI가 음성 입력을 1급으로 취급하기 시작했다"는 신호로 기억.

**🟦 Claude Code / MCP — 헤드리스 첫 턴의 MCP 대기시간 제어**

- 출처: [CHANGELOG 2.1.274](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
- 💡 핵심: 비대화형(`-p`) 세션의 첫 턴이 MCP 서버 연결을 얼마나 기다릴지 `CLAUDE_CODE_MCP_STARTUP_WAIT_MS`로 상한을 걸 수 있다. `0`이면 아예 안 기다린다.
- 📝 방법:

```bash
# CI에서 MCP가 필수가 아닐 때: 연결 대기 없이 바로 시작
CLAUDE_CODE_MCP_STARTUP_WAIT_MS=0 claude -p "lint 결과 요약해줘"

# MCP가 필수일 때: 상한만 걸어 행 방지
CLAUDE_CODE_MCP_STARTUP_WAIT_MS=10000 claude -p "DB 스키마 검사"
```

- 🎯 언제: MCP 서버가 뜨다 마는 CI/스케줄 잡에서 첫 턴이 하염없이 기다리는 문제를 끊을 때.
- ⚠️ 주의: `0`으로 두면 느리게 뜨는 서버의 툴은 첫 턴에 안 보일 수 있다. 필수 MCP라면 상한을 0이 아닌 값으로.
- ⭐ 추천도: 헤드리스로 Claude Code를 돌리는 팀이라면 오늘 바로 적용 가치.

**🟪 공통 / Context — 멀티에이전트 결과는 append-only 로그로 모아라 (Agora 패턴)**

- 출처: [arXiv 2609.18094](https://arxiv.org/abs/2609.18094)
- 💡 핵심: 병렬 에이전트가 서로의 결과를 못 보면 컴퓨트는 중복 탐색에 샌다. 공유 상태는 "수정 가능한 문서"가 아니라 **불변 기여 + 출처 링크**여야 충돌 없이 쌓인다.
- 📝 방법 (축소판): 탐색 결과를 공유 저장소의 `findings/` 디렉터리에 1건 = 1파일 = 1커밋으로 발행하게 하고, 커밋 메시지에 근거가 된 이전 finding의 해시를 적게 한다. 새 에이전트 프롬프트에는 최신 인덱스(파일 목록 + 한 줄 요약)만 주입.
- 🎯 언제: 에이전트 2개 이상이 같은 문제 공간(리팩터 후보 탐색, 파라미터 스윕, 버그 원인 조사)을 나눠 뒤질 때.
- ⚠️ 주의: 논문 스스로 "공유 상태가 컴퓨트당 발견을 늘린다"는 통제 비교는 미완이라고 밝힌다. 쏠림 방지(다양성 규칙)를 빼면 전원이 1등 가설만 판다.
- ⭐ 추천도: 인프라 추가 없이 git만으로 시작 가능 — 멀티에이전트를 굴리는 팀이라면 이번 주 실험감.
