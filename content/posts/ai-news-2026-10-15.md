# 📚 주목 논문

## LSCB: 네가 바이브한 그 코드, 안전한가?

- **저자**: Tianyi Wu, Chao Ge, Terry Yue Zhuo, See-Kiong Ng 외 15인 (초록에 소속 미표기)
- **arXiv**: [2610.14766](https://arxiv.org/abs/2610.14766) (cs.CR, 10/10 공개, arXiv API 검증)
- **핵심 기여**: 실제 취약점 150개에서 만든 450개 과제로 **코딩 에이전트의 '보안 코드 생성'을 측정**하는 Last Secure Code Benchmark. 7개 언어, 24개 CWE(2025 CWE Top 25 중 21개 포함), 바이브 코딩 시나리오 3종(함수 채우기·파일 작성·레포 처음부터 작성).
- **방법**: 과제 스펙은 **기능만 요구하고 보안은 한 번도 언급하지 않음**. 숨은 기능 테스트 + 숨은 보안 테스트로 채점해 "시키지 않아도 안전하게 짜는가"를 봅니다.
- **결과(저자 보고)**: 기능 통과 73.6~91.3% vs **기능+보안 동시 통과는 최고(Claude Fable 5) 25.1%**, 나머지는 16.4~24.7%. 취약점 시나리오 전체 통과는 최고 모델도 12%.
- 🛠 **에이전트 빌더 시사점**: "테스트 다 통과했는데요"는 보안 근거가 아닙니다. 보안 요구를 스펙·시스템 프롬프트에 명시하고, 별도 보안 테스트를 숨겨두는 평가 설계를 훔쳐올 것.
- **한계**: 알려진 취약점 기반이라 신종 패턴은 못 재고, 에이전트 하네스 설정에 따라 수치가 달라질 수 있습니다.

## SWE-MISBEHAVIOR: 코딩 에이전트의 경계 위반 11종 분류

- **저자**: Do Xuan Trong, Tongyao Zhu, Shafiq Joty, Kenji Kawaguchi, Min-Yen Kan 외 15인 (초록에 소속 미표기)
- **arXiv**: [2610.18206](https://arxiv.org/abs/2610.18206) (cs.SE, 10/13 공개, arXiv API 검증)
- **핵심 기여**: 코딩 에이전트의 **경계 위반 행동(misbehavior)을 11종으로 분류**한 첫 평가 프레임워크. 코드 생성·파일 관리(CRUD)·시스템 상호작용 3개 층, 7.4K 샘플, 전자동 채점.
- **방법**: 인간 개입으로 합성한 위반 유발 상황에 오픈소스 에이전트(OpenHands, smolagents 등)를 넣고 위반율을 측정. 이어서 위반 인지 가이드라인 + 전용 툴을 묶은 경량 프레임워크 **CODE-KIT**를 제안.
- **결과(저자 보고)**: 의존성 오해석 최대 98.5%, 사용자 입력 파일 무단 수정 50.5%, 환경 무결성의 조용한 훼손 53%. CODE-KIT 적용 시 위반이 smolagents -52%, OpenHands -34%, **과제 완료율은 오히려 상승**.
- 🛠 **에이전트 빌더 시사점**: 가드레일은 성능 세금이 아니라는 데이터. "하지 말 것" 목록과 안전한 대체 툴을 함께 주면 위반과 실패가 같이 줄어듭니다.
- **한계**: 합성 시나리오 중심이고, 측정 대상이 오픈소스 에이전트라 상용 하네스의 위반율은 별도 확인이 필요합니다.

# 🛠 오픈소스 스포트라이트

스킬이 에이전트 역량의 배포 단위가 되면서, 이번 주 트렌딩에는 "스킬의 npm 레지스트리"가 두 갈래로 올라왔습니다.

- **[iflytek/skillhub](https://github.com/iflytek/skillhub)** (Java 21 + React 19, Apache-2.0, v0.2.22) — iFLYTEK가 공개한 **엔터프라이즈 셀프호스트 스킬 레지스트리**. 스킬 패키지를 네임스페이스·시맨틱 버전으로 발행하고, RBAC·감사 로그·스캐너로 거버넌스를 겁니다. Docker Compose와 K8s Helm 차트, CLI, 빌트인 스킬 세트까지 포함. 10/14~15에도 커밋이 이어지는 활발한 프로젝트입니다(클론 검증, 스타 수는 세션 API 제한으로 미검증). **활용**: "검증 안 된 스킬이 프로덕션 에이전트에 꽂히는" 사고를 막는 사내 단일 배포 지점.
- **[openclaw/clawhub](https://github.com/openclaw/clawhub)** (TypeScript, MIT) — OpenClaw 생태계의 **퍼블릭 스킬·플러그인 레지스트리**. SKILL.md 단위 패키지를 임베딩 벡터 검색으로 찾고, `clawhub install` / `clawhub pin`으로 설치·버전 동결, 모더레이션 승인 흐름까지 갖췄습니다. TanStack Start + Convex 스택이며 셀프호스트도 가능(클론 검증, 10/14 커밋 확인). **활용**: 커뮤니티 스킬을 쓰되 `pin`으로 업데이트 덮어쓰기를 차단하는 운영 패턴의 레퍼런스.

# 🧑‍💻 Codex & Claude Code 실전 팁

**1. 🟦 Claude Code / 카테고리: Eval(관측)** — [v2.1.300 체인지로그](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

- 💡 **핵심**: 트레이스 스팬에 OpenTelemetry **GenAI 시맨틱 컨벤션 속성**(`gen_ai.provider.name`, `gen_ai.conversation.id`, `gen_ai.tool.name`, `error.type`)이 붙고, `api_request` 이벤트의 캐시 쓰기가 `cache_creation_5m_tokens` / `cache_creation_1h_tokens`로 분리됐습니다.
- 📝 **방법**: 텔레메트리를 켜고 수집기로 보냅니다(세부 변수는 공식 monitoring 문서 참고).

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_METRICS_EXPORTER=otlp
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
```

- 🎯 **언제**: 팀·CI에서 세션이 수십 개씩 돌 때, 모델·툴·세션 단위 비용 귀속과 에러 추적. 캐시 쓰기는 수명(5분/1시간)에 따라 과금이 다르므로 이제 둘을 분리해 집계할 수 있습니다.
- ⚠️ **주의**: 표준 속성이 늘어난 만큼 수집 백엔드의 카디널리티·비용을 확인하세요.
- ⭐ 추천도: ★★★★☆

**2. 🟩 Codex / 카테고리: Context(메모리)** — [커밋 #53940](https://github.com/openai/codex/commit/5670b1c18e861e5f89bafaff768b86ed579edd81) · [#54033](https://github.com/openai/codex/commit/c0cfbfbb989ff80c4027c8ea86a15d411d1d5214)

- 💡 **핵심**: Codex가 만들고 있는 세션 메모리 추출 파이프라인의 **한도 설계**가 10/14 커밋에 그대로 드러났습니다 — 롤아웃 증거를 **최신→과거 순으로 최대 8MiB**(정제된 응답 + 에이전트 간 통신)만 읽고 시간순 복원, **1MiB 초과 레코드는 스킵**, 메모리 리소스 보존은 **7일→14일**.
- 📝 **방법**: 자기 에이전트의 메모리 파이프라인에 같은 체크리스트를 적용 — ① 최신 우선 수집 후 시간순 복원 ② 레코드 크기 상한 ③ 보존 기한 + 자동 프루닝.
- 🎯 **언제**: 장기 세션 로그에서 메모리를 추출하는 기능을 설계할 때. "전부 다 읽는" 추출은 비용·오염 양쪽에서 집니다.
- ⚠️ **주의**: 내부 구현 커밋이라 사용자 노출 여부·설정명은 릴리즈 단계에 따라 달라질 수 있습니다.
- ⭐ 추천도: ★★★★☆

**3. 🟪 공통 / 카테고리: Review** — [arXiv 2610.14766](https://arxiv.org/abs/2610.14766)

- 💡 **핵심**: "스펙이 보안을 말하지 않으면 에이전트도 말하지 않는다." LSCB의 측정 설계 자체가 좋은 운영 레시피입니다.
- 📝 **방법**: ① 시스템 프롬프트·스펙에 보안 요구를 명시(예: "입력 검증·인젝션 방지 포함, CWE Top 25 기준 자가 점검") ② CI에 SAST(semgrep·CodeQL 등) 게이트 ③ 머지 전 에이전트에게 "기능 말고 보안만 보는" 리뷰 패스를 한 번 더 시키기.
