# 📚 주목 논문

## 1. 궤적 단위 불확실성 측정 — 단일 턴 confidence는 그대로 안 옮겨간다

- **저자**: Dylan Bouchard, Mohit Singh Chauhan
- **arXiv**: [2608.11552](https://arxiv.org/abs/2608.11552) (cs.CL, 8/12 제출)
- **핵심 기여**: 단일 응답 기준으로 만들어진 불확실성 측정(UQ) 기법들이 **다중 턴 에이전트 궤적**에서도 통하는지 처음으로 체계 비교했다.
- **방법**: LLM 5종 × BFCL-v4 / τ²-bench의 멀티턴 도구 사용 데이터셋 4종에서 세 계열을 평가 — 액션 토큰 확률 기반 white-box, 궤적 리샘플링 기반 black-box 자기일관성, 모델 자기평가 기반 reflexive.
- **결과**: 이전은 되지만 **고르지 않다.** 토큰 확률 점수는 턴 간 집계 방식(aggregator) 선택에 매우 민감했고, reflexive가 가장 싼 baseline으로 쓸 만했으며, **black-box 자기일관성이 대체로 가장 강한 계열**(그중 궤적 동등성·액션 집합 일관성 변형이 상위)이었다.
- **🛠 에이전트 빌더 시사점**: 로짓 접근 없이도 되는 **리샘플 K회 + 액션 집합 일치율**을 승인 게이트 신호로 쓰는 게 현재 가성비가 가장 좋다. 단일 턴 confidence를 그대로 재활용하지 말 것.
- **⚠️ 한계**: 도구 사용 벤치마크 위주라 장기 자율 작업으로의 일반화는 미검증. 리샘플링은 K배 비용을 그대로 문다.

*불일치가 클 때만 사람을 부른다. 승인 피로도를 위험 구간에 집중시키는 구조. 근거: arXiv 2608.11552. 자체 제작 도식.*

## 2. 엔터프라이즈 MCP 인증 게이트웨이 — "사람 아닌 호출자" 문제

- **저자**: Suraj Kumar, Amy Wang, Srinivasan Manoharan
- **arXiv**: [2608.10760](https://arxiv.org/abs/2608.10760) (cs.CR, 8/11 제출)
- **핵심 기여**: 1년 만에 사내 MCP 서버가 0개에서 수십 개로 늘면서 생긴 거버넌스 붕괴를, **중앙 MCP 게이트웨이** 하나로 수습한 실제 프로덕션 배포 보고서.
- **방법**: 팀마다 제각각(무인증 / API 키 / 완전 OAuth)이던 걸 **2축 인증 모델**로 정리한다 — 페르소나(대화형 사용자 vs 자동화된 비사용자) × 자격증명 타입(무인증, 정적·동적 API 키, PKCE, client credentials, 플랫폼 앱 컨텍스트). 토큰 조달은 BYOT / GYOT / RFC 8693 토큰 교환 기반 위임 OAuth 세 가지.
- **결과**: 웹·데스크톱·커스텀 SDK·로우코드 클라이언트에 걸쳐 수십 개 MCP 서버를 실제로 프론팅 중.
- **🛠 에이전트 빌더 시사점**: MCP를 여러 개 붙이기 시작한 순간 **"퇴사자 오프보딩을 전체 서버에서 어떻게 한 번에 하나"** 가 바로 문제가 된다. 서버마다 인증을 짜지 말고 게이트웨이에서 한 겹으로 잡아라. 특히 사람이 아닌 자동화 호출자의 신원을 **처음부터 별도 페르소나로** 설계할 것.
- **⚠️ 한계**: 단일 조직 경험 보고이고 정량 비교 평가는 없다. 게이트웨이 자체가 단일 장애점이 된다.

## 🟪 공통 — 리샘플 3회로 "커밋 전 자기일관성 게이트" 만들기

- **카테고리**: Eval / Context
- **출처**: [arXiv 2608.11552](https://arxiv.org/abs/2608.11552)
- **💡 핵심**: 위 논문 결론을 그대로 쓴다 — 되돌릴 수 없는 액션(배포, 마이그레이션, 외부 쓰기) 직전에 **궤적을 3회 리샘플해 액션 집합이 일치하는지**만 본다. 로짓 접근이 필요 없어 어느 API에서든 된다.
- **📝 방법**:

```python
# 되돌릴 수 없는 액션 앞에서만 호출 (K배 비용을 여기에만 쓴다)
def consistency_gate(run_agent, task, k=3, threshold=1.0):
    action_sets = []
    for _ in range(k):
        traj = run_agent(task)                       # 궤적 전체를 재생성
        action_sets.append(frozenset(
            (step.tool, step.target) for step in traj  # 인자 전체 말고 식별자만
        ))
    agree = action_sets.count(action_sets[0]) / k
    return agree >= threshold, agree                 # 불일치면 사람에게 에스컬레이션
```

- **🎯 언제**: 자율 에이전트가 프로덕션에 영향을 주는 액션을 실행하기 직전.
- **⚠️ 주의**: 모든 스텝에 걸면 비용이 K배로 폭발한다. **위험 액션에만** 걸 것. 그리고 일관성은 정확성이 아니라 **안정성** 지표다 — 셋 다 똑같이 틀릴 수 있다.
- **⭐ 추천도**: ★★★★★ — 오늘 브리핑에서 가장 실행 가치가 높은 항목.
