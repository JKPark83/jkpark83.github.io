# 🔥 오늘의 핵심

지난 브리핑(9/13) 이후 가장 큰 변화는 **오픈 웨이트 에이전틱 모델이 양 극단에서 동시에 풀린 것**이다. 상하이 AI 랩이 744B MoE **Atria Dawn Preview**를 MIT 라이선스로, 중관춘 연구진이 7.39B **ZGCM-1**을 학습 데이터·코드·W&B 로그까지 통째로 공개했다. 오늘 해볼 일: Atria의 무료 프리뷰 API에 기존 에이전트 태스크 하나를 물려 프론티어 API와 비교해보기.

# 🤖 모델 & 릴리즈 레이더

- **Atria Dawn Preview (9/11 HF 공개, 9/14 기술 리포트)** — 상하이 AI 랩이 GLM-5.2(744B MoE)를 베이스로 포스트트레이닝한 에이전틱 모델. "문제 분석→설계→툴 사용→코드→실험→실패 복구"의 리서치 루프 전체가 타깃이다. MIT 라이선스, 256K 컨텍스트, 텍스트 전용. vLLM(0.23.0+)·SGLang(0.5.13+) 배포를 지원하고 OpenAI 호환 무료 프리뷰 API도 열었다. 모델 카드 기준 BrowseComp 92.5, Terminal-Bench 78.3, BFCL v4 77.0 — 자체 발표 수치라는 점은 유의. [HF 모델 카드](https://huggingface.co/internlm/Atria-Dawn-Preview) · [기술 리포트](https://arxiv.org/abs/2609.15818)
- **Claude Code 2.1.271→273** — 사흘 새 세 릴리즈(저장소 클론으로 확인). 에이전트 빌더에게 중요한 것 셋: ① auto 모드 샌드박스에서 **명령별 `allowed_domains`** — Bash 명령이 필요로 하는 호스트만 그 명령에 한해 열어준다, ② 서브에이전트 프론트매터의 **`omitClaudeMd`** — CLAUDE.md 없이 도는 경량 서브에이전트 정의 가능, ③ `--remote-control` 세션을 포크해 백그라운드 세션으로 돌리는 기능. [체인지로그](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
- **Codex CLI는 조용한 주** — 릴리즈는 0.154.0에서 멈춰 있지만, main 브랜치에는 `/usage` 계정 분석 대시보드(플랜 사용 이력·Top chats·스택 차트) 커밋이 연달아 합류했다(클론으로 확인). 차기 릴리즈에서 토큰 지출 가시화가 크게 좋아질 전망.

![오픈 웨이트 에이전틱 모델 비교](/images/ai-news-2026-09-16/open-weights.svg)

*같은 주에 공개된 744B와 7.39B — 규모가 갈리는 지점(광역 웹 리서치)과 소형이 버티는 지점(수학·좁은 툴 검색)이 뚜렷하다. 모두 자체 발표 수치.*

# 📚 주목 논문

## ZGCM-1: 수학·에이전틱 검색용 풀오픈 7B (arXiv 2609.13356, cs.AI)

- **저자**: Jiyan He 외 22명 — 중관춘 아카데미·중관춘 인공지능연구원 (9/11 공개, HF Daily 291 upvotes)
- **핵심 기여**: 7.39B dense 모델을 처음부터 학습하고, **프리트레인·미드트레인·포스트트레인 전 단계의 가중치, 중간 체크포인트, 학습 코드, 데이터 레시피, W&B 로그까지 공개**. "소형 모델은 웹을 암기할 수 없으니, 내부 추론 + 외부 툴 사용으로 용량 한계를 넘는다"는 설계 전제가 명확하다.
- **방법**: 게이트드 슬라이딩 윈도우와 풀 어텐션을 교차 배치한 하이브리드 어텐션, FP8 Muon 옵티마이저, 점진적 롱컨텍스트 미드트레이닝, 에이전틱 SFT. 256K 컨텍스트에서 풀 어텐션 대비 3.94배 학습 처리량(리포트 자체 실험).
- **검증된 결과**: MATH-500 97.13, AIME 2026 75.0, HMMT 2025 70.42로 비교된 7–8B 7종 중 추론 평균 랭크 1위(자체 리포트). 툴 검색은 WebWalkerQA 63.09, Binary Function Search 62.0.
- 🛠 **에이전트 빌더 시사점**: 태스크가 좁고 툴이 붙는다면 7B 자체 호스팅이 실전 옵션이라는 또 하나의 실측. 전체 레시피가 있으니 자기 도메인용 소형 에이전트 모델의 출발점으로 삼을 수 있다.
- **한계**: BrowseComp 19.43 — 광역 웹 리서치는 여전히 대형 모델의 영역이다.
- [arXiv 링크](https://arxiv.org/abs/2609.13356)

## Dream-RSI: 리플레이 시뮬레이터에서 "꿈꾸며" 탐색 전략을 개선 (arXiv 2609.14858, cs.CL)

- **저자**: Tong Zheng 외 17명 — Google (9/14 공개, HF Daily 260 upvotes)
- **핵심 기여**: 에이전트의 자기 개선에서 병목인 **탐색 전략 관리**를 다룬다. 고정 전략은 탐색 공간이 커지면 못 버티고, 온라인 정책 최적화는 롤아웃이 너무 비싸다는 딜레마가 출발점.
- **방법**: 코딩 에이전트는 그대로 두고, 탐색을 명시적·프로그래머블하게 만드는 경량 오케스트레이션 레이어를 얹는다. 누적된 발견 히스토리(탐색 트리)를 **리플레이 시뮬레이터**로 재구성하고, 그 안에서 "dreaming" — 저비용 오프폴리시 평가 — 으로 탐색 정책을 개선한 뒤 온라인에 재배포한다.
- **결과**: 알고리즘 엔지니어링, 수학 최적화, GPU 커널 엔지니어링에서 발견 품질은 유지·개선하면서 발견 비용을 상당히 절감(초록 기준, 세부 수치는 본문 참조).
- 🛠 **에이전트 빌더 시사점**: 지금 버리고 있는 에이전트 실행 로그가 "탐색 전략 튜닝용 시뮬레이터"가 될 수 있다는 관점 전환. 값비싼 A/B 롤아웃 전에 히스토리 리플레이로 전략을 거르는 패턴은 당장 베낄 만하다.
- **한계**: 리플레이는 이미 실현된 탐색 공간에 갇힌다 — 분포 밖 전략 평가는 보장이 약하다.
- [arXiv 링크](https://arxiv.org/abs/2609.14858)

# 🧑‍💻 Codex & Claude Code 실전 팁

## 🟩 Codex — Codex에도 이제 SKILL.md가 있다

- **분류**: Context · **출처**: [공식 스킬 문서](https://developers.openai.com/codex/skills) (구현은 codex-rs의 `skills` 크레이트로 확인)
- 💡 **핵심 아이디어**: 재사용 프롬프트 묶음을 `SKILL.md`로 디스크에 두면 Codex가 자동 발견한다. 컨텍스트에는 이름·설명·경로만 주입되고 본문은 필요할 때만 읽는다 — 토큰이 절약되는 구조.
- 📝 **방법**:

```bash
mkdir -p ~/.codex/skills/release-check
cat > ~/.codex/skills/release-check/SKILL.md <<'EOF'
---
name: release-check
description: 릴리즈 전 체크리스트를 순서대로 실행한다
---
1. 테스트 전체 실행, 2. CHANGELOG 갱신 확인, 3. 버전 태그 규칙 검사 ...
EOF
# 세션에서: $release-check 로 호출, /skills 로 목록 탐색
```

- 🎯 **언제**: 팀 공통 절차(릴리즈, 리뷰, 마이그레이션)를 매번 프롬프트로 붙여넣고 있다면.
- ⚠️ **주의**: 초기엔 experimental 플래그 뒤에 있던 기능이라 구버전은 `config.toml`에 `[features] skills = true`가 필요할 수 있다. Claude Code의 SKILL.md와 개념은 같지만 프론트매터 요구 사항이 달라 그대로 복사하면 검증 오류가 날 수 있다.
- ⭐ **추천도**: Claude Code에서 스킬 맛을 본 팀이라면 Codex 쪽도 바로 통일할 가치.

## 🟦 Claude Code — /ralph-loop: 완료 조건까지 자동 반복

- **분류**: Hook · **출처**: [plugins/ralph-wiggum](https://github.com/anthropics/claude-code/blob/main/plugins/ralph-wiggum/README.md) (클론으로 확인)
- 💡 **핵심 아이디어**: 공식 저장소에 번들된 이 플러그인은 Stop hook으로 세션 종료를 가로채 **같은 프롬프트를 다시 주입**한다. 외부 bash 루프 없이 세션 안에서 "될 때까지" 반복하는 Ralph 기법의 구현체다.
- 📝 **방법**:

```text
/ralph-loop "todos REST API 구현. CRUD + 입력 검증 + 테스트.
끝나면 <promise>COMPLETE</promise> 출력" --completion-promise "COMPLETE" --max-iterations 50
```

- 🎯 **언제**: 테스트 스위트 통과가 완료 조건인 밤샘 작업, 벤치마크 점수 올리기 같은 "반복이 곧 진전"인 태스크.
- ⚠️ **주의**: 토큰 소모가 크다. `--max-iterations`는 반드시 걸고, 완료 약속 문구는 우연히 출력되지 않을 문자열로. 멈추려면 `/cancel-ralph`.
- ⭐ **추천도**: 반복 조건이 기계적으로 판정 가능한 태스크라면 강력 추천.

![ralph-loop 동작 구조](/images/ai-news-2026-09-16/ralph-loop.svg)

*Stop hook이 종료를 가로채 같은 프롬프트를 재주입하는 구조. 진행 상태는 파일과 git 이력이 담당한다.*
